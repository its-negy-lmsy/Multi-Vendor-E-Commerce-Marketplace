# 10-minute capstone presentation outline

1. Problem and audience — 1 min: independent makers need a trusted storefront and buyers need curated discovery.
2. Product identity and core flow — 1 min: Common Goods, customer sign-in, published product catalog and intended multi-vendor journey.
3. Architecture — 2 min: React/Vite/Redux client; Express API; MongoDB source of truth; Redis/Elasticsearch projections; storage and payment adapters.
4. Data and security — 1.5 min: integer paise, role checks, refresh rotation, order snapshots, idempotency and auditable ledger.
5. Demonstration — 2 min: sign in, load MongoDB catalog, show role-protected endpoint and validation response.
6. Verification and challenges — 1 min: show executed checks only, service credential blockers and test coverage gaps.
7. Next steps — 1.5 min: vendor approval/product moderation, Redis/search sync, checkout/webhooks, test suite, deployment and responsive review.
